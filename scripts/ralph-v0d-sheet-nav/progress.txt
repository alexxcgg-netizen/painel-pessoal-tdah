Contrato novo que outras faixas vao usar (documentado tambem no topo do .js)
- Formulario dentro de um sheet que deve fechar sozinho ao salvar com sucesso: atributo
  `data-fecha-ao-enviar` no <form> + no handler de sucesso (DEPOIS do fetch confirmar,
  nunca so no submit) disparar:
    form.dispatchEvent(new CustomEvent("bottomsheet:sucesso", { bubbles: true }))
  bottom-sheet.js ouve isso delegado no document e fecha o sheet ancestral mais proximo.
- Gatilhos declarativos prontos (fora da API chamada na mao): `data-abre-sheet="id"` num
  botao abre esse sheet no clique; `data-fecha-sheet` dentro de um sheet fecha o ancestral.

  com um numero curto dentro. Estilo ja pronto em navegacao.css, so falta o HTML (P1b poe
  isso na aba Hoje).
