# Progresso — N3cd: Widget Docs (Documentação de Opções de Widget do iPhone)

## Objetivo
Documentar 5 opções de widget para iPhone que leem o endpoint `/api/widget` (JSON) e `/widget` (HTML).
Sem código de produção; apenas documentação para o Alex testar e escolher.

## Histórias Concluídas

### N3c: Documentação de Widgy e API Widget
- [x] docs/widget-widgy.md: Configuração do app Widgy, mapeamento JSON paths, exemplos por tamanho de widget
- [x] docs/widget-api-widget.md: Configuração de apps "API Widget"/"API Widgets", mapeamento JSON paths, exemplos por tamanho

### N3d: Documentação de Glimpse 2, Atalhos e Tabela Comparativa
- [x] docs/widget-glimpse.md: Configuração do Glimpse 2 (renderiza página HTML /widget), exemplos por tamanho
- [x] docs/widget-atalhos.md: Atalho 1 (obter dados e exibir), Atalho 2 (widget na tela de início), Atalho 3 (captura rápida iOS 17+)
- [x] docs/widget-comparativo.md: Tabela em branco para Alex preencher testando Scriptable, Widgy, API Widget, Glimpse 2, Atalhos, WidgetKit nativo
